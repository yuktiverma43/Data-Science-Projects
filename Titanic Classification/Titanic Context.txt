Build a model on training set and make prediction on test set whether the person survived or not.

Data Dictionary used in project:-

survival: Survival with values 0 = No, 1 = Yes
pclass: socio-economic status (SES) 1st = Upper 2nd = Middle 3rd = Lower
sex: Male and Female
Age: in years
sibsp: # of siblings / spouses aboard the Titanic sibsp: The dataset defines family relations in this way... Sibling = brother, sister, stepbrother, stepsister Spouse = husband, wife (mistresses and fiancés were ignored)
parch: # of parents / children aboard the Titanic parch: The dataset defines family relations in this way... Parent = mother, father Child = daughter, son, stepdaughter, stepson Some children travelled only with a nanny, therefore parch=0 for them.
ticket: Ticket number
fare
cabin: Cabin number
embarked: Port of Embarkation with values C = Cherbourg, Q = Queenstown, S = Southampton
